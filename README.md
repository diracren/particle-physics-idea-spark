# Particle Physics Idea Spark — 实验选题版

从给定粒子物理方向筛选当前可开展的测量课题，并给出有证据支持的投稿定位。默认 3–5 个逐题审查的候选，深化前 1–2 个；也支持单题深化与理论/唯象研究。

## 选题原则

优先关注关键参数及跑动、形状因子与非微扰输入、奇特强子重要性质、EEC/碎裂等 QCD 规律测量、真实的理论—实验张力、对称性/稀有过程与重要基础输入。精度、覆盖、独立性和模型判别力均可构成贡献，不要求新算法；与理论一致或消除旧张力的结果同样可能重要。

## 使用示例

- “使用 particle-physics-idea-spark，在 EEC 方向筛选 3–5 个目前可做的实验课题，重点看 QCD 演化与强子化。按物理价值和可行性排序，给基准期刊及冲击更高影响期刊的条件。我有……实验、……能区、……样本和权限。”
- “围绕奇特强子的自旋宇称、相位运动和耦合关系，找能区分结构解释的测量；先核查已有工作，再给 PRL/领域期刊定位的同类论文依据。”
- “审查这个形状因子测量是否能裁决理论—实验差异：……。如果结果与理论一致，仍有何价值，适合什么期刊？”

## 输出与判断

五阶段：证据/实验能力 → 物理价值与瓶颈 → 逐题可达性 → 独立审查/期刊校准 → 排序清单和重点卡片。

写作从“这项测量比现在多告诉我们什么”出发，不靠“填补空白、统一框架、有望冲击PRL”等表述代替物理判断。先给推荐及取舍，再讲关键证据、目标与限制；标题具体到过程、测量量或态的性质。

文献、误差预算、查重、审查和期刊参照仍逐题保存在后台。面向用户的文稿按物理问题组织，不同时重复总表、简卡、详卡和三套期刊分支。新的 references/research-writing.md 说明具体要求与改写示例；示例数字不是任何实际实验的预测。正式申请书保留正式语气，不用刻意口语化或装作专家经历来“去AI味”。

可行性分 A 当前可开展完整测量、B 当前可做可行性但完整测量有前提、C 依赖未来资源。未知权限不当作已有权限，C 单列展望。期刊给基准定位、条件性上限、范围受限时定位；逐题用 2–4 篇已发表同类论文和官方范围校准，不承诺录用、不默认等同 JCR/中科院分区。

入口为 SKILL.md；references 包含文献指南、实验选题指南、物理策略、期刊定位、审查协议、课题清单及详细卡片模板。产物位于当前工作区 particle_ideas 的新目录，每题使用独立稳定 ID。

## 安装与能力边界

完整文件夹安装至宿主技能目录（DSH 通常为 ~/.dsh/skills/）；依宿主刷新技能列表。需要文件读写和真实网络检索，推荐独立子代理审查及 PDF 阅读能力，无强制 Python 包/API 密钥。不提供自动检索状态机或物理验证软件。资料不足时标明条件，不虚构全文阅读、实验性能、模拟或期刊依据。

独立改写自 idea-spark 的设计原则，不依赖原版 ML 语料/脚本。策略是领域启发式，不是经论文统计验证的创新规律。文件验证不等于已针对某实验完成选题或验证期刊判断。
