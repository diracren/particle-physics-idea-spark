# 实验选题：从关键物理到当前可做的测量

## 核心原则

实验贡献可以是新数据、新精度、新运动学覆盖、独立系统学或新物理判别力，不要求方法、模型或观测量本身全新。重要的精度提升、独立复核、严格上限和与标准模型一致的结果均有价值；不能以没有异常或没有新算法拒绝课题。一个观测量可以服务多个目标，必须说明主要目标与实际可获得的信息。

每个候选写完整链条：**科学问题 → 关键参数/物理函数/态性质 → 可测分布或计数 → 提取与理论解释 → 所需精度 → 当前实验能力 → 新增知识**。不得把测到分布等同于已经无模型依赖地提取理论对象。

## 七类高价值入口

| 入口 | 可扩展的对象 | 必须回答的价值问题 |
|---|---|---|
| 基本参数与尺度演化 | αs(Q)、有效电磁耦合、CKM 元素、混合参数、质量与寿命 | 是否填补关键 Q 区间、改变世界平均、检验跑动或减少全局拟合退化？明确方案、阈值匹配及相关误差 |
| 强子结构与非微扰输入 | 时样/空样形状因子、相位、半轻衰变形状、PDF/TMD、碎裂函数 | 哪些形状/归一化/味道组合可被约束？对格点、色散、因子化或其他精密测量有何影响？ |
| 奇特强子与谱学 | 质量、宽度、J^PC、极点、耦合、分支比、相位运动、产生与衰变模式 | 是否区分阈值效应、共振和不同内部结构？峰的位置不等于极点；单一质量或峰值显著性通常不足以判定组成 |
| QCD 动力学与普适性 | EEC/多点能量关联、喷注、碎裂、标度破缺、强子化过渡 | 是否跨尺度检验微扰到非微扰的连接、演化、因子化或普适性？定义粒子级、带电/全粒子、归一化及角区 |
| 理论—实验或实验间张力 | 最新平均值与可靠理论预言的差别、不同实验/方法的不一致 | 新测量能否裁决具体解释，而不是仅增加一个同系统学的数据点？ |
| 对称性与稀有过程 | CP、轻子味道/普适性、禁戒衰变、守恒律与零检验 | SM 背景是否受控？空结果能否排除有意义参数区间或提高关键检验精度？ |
| 关键基础输入与缺失区域 | 截面、R 比、分支比、核/强子输入、稀缺能区和衰变道 | 是否解除下游测量的主导误差、改善色散积分或形成后续实验必需输入？明确误差传播与用户群 |

参数、函数与测量量的类别不能混淆：EEC 是相关观测量，碎裂函数是需在因子化框架中提取的非微扰对象；形状因子依赖过程和运动学。模型判别要求比较受数据允许的模型范围，而非挑两条固定曲线。

## 张力优先，但先审计真实性

对每个声称的差异记录：最新实验值与日期、理论版本与输入、共同定义/相空间/辐射修正、实验及理论误差和相关性、显著性来源、局部/全局及试验因子、后续更新。区分严格理论预言、受控近似、现象模型和生成器调参；数据与某个生成器不同不自动构成基本理论危机。

单一高斯量仅在误差模型合适时使用 z=(x_exp-x_th)/sqrt(V_exp+V_th-2 Cov(exp,th))；多维分布需适用的联合似然或完整协方差，归一化导致奇异协方差时处理独立自由度。理论误差非高斯/没有概率解释时不能硬凑 sigma；报告假设依赖区间。不得把多个相关 bin 的差异当作独立发现。

构造“裁决测量”：竞争解释各自预言什么，在哪个能区/角区/衰变道差别最大，新增测量的误差必须低到什么水平才能区分。必须同时评估三种结局的价值：确认差异、消除差异、仍无法判别。不要用预期发现作为唯一发表依据。

## 当前可行性档案

优先获取三个信息组（已有上下文则不再问）：
1. 实验/平台、能区、粒子种类、已采集数据量与可用数据权限；
2. 探测器性能、触发/重建/PID、模拟与控制样本、已有分析基础；
3. 人力/时限、理论或分析支持、合作组内已知相近项目。

未知时仍做公开文献和物理价值筛选，明确条件化场景；不得把用户是实验工作者推断成拥有特定合作组的数据权限。公开记录不能揭示内部项目占用，标记“需组内核实”。数据采集完成不等于用户可分析或发表。

逐题标记：A 现有可访问数据与工具足以开始完整分析；B 可立即做可行性研究，但完整测量依赖未确认的数据/校准/权限；C 必须新增取数、升级装置或等待未来设施。只有 A 可无条件列为“当前可开展测量”；B 写出升级到 A 的条件；C 单列展望，不挤占当前课题名额。

最低可达性预算：数据量及来源、有效产额/纯度、接受度效率与迁移、目标精度、当前精度、统计误差、前 3 项系统误差、理论解释误差、必要的控制样本。所有数值标注已知/计算/情景假设；缺数据给区间和敏感性分析，不伪造单点预测。亮度增加只能按适用项缩放统计误差，不能默认系统误差按 1/sqrt(L) 改善。

计数测量可估 N=L σ B A ε，明确哪些因素已包含在 σ 或效率中；分布/拟合测量需考虑 bin 迁移、展开、模型依赖和协方差。需要联合参数提取时评估 nuisance profiling、参数相关与理论输入。不把 toy 灵敏度当已完成全模拟。

## 优先级规则

先过数据权限、可测性、主导误差与有意义精度门槛，再做比较。分别用高/中/低/未知及证据评估：物理重要性、预期知识增量、理论解释成熟度、当前可行性、系统学可控性、独立性/时效性。未知不计零分；不用无依据的精确总分或期刊等级替代物理判断。

推荐顺序说明最关键的权衡，可列首选、稳健备选、高风险高回报。精度改进需量化是否改变物理判断/世界平均/模型约束；首次测量需说明为何该空白关键。独立复核要说明数据、装置或系统学是否真正独立。优先级不得只按异常显著性排序。
