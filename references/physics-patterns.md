# 粒子物理创意策略卡

这些是领域启发式，不是由已验证论文语料提取的成功率，也不构成创新证明。选策略必须指出它如何消除已证实的瓶颈。

| 策略 | 适用瓶颈与操作 | 必须产生的物理贡献 | 常见失败 |
|---|---|---|---|
| 对称性保护与零检验 | 找出对称性限制下为零/受抑制的组合，推导破缺项及 SM 污染 | 可定量控制的 null test 或选择定则 | 把探测器不对称、末态相互作用或高阶 SM 效应当新物理 |
| 有效场论匹配与跨尺度联系 | 明确自由度、基底、匹配尺度、RG 演化及截断阶次 | 可检验的跨过程关系或此前遗漏的受控贡献 | 基底重命名、EOM 冗余、超出截断有效域 |
| 互补可观测量破除退化 | 推导不同过程/能区/极化对参数的独立敏感方向 | 可识别性改善及其物理原因 | 把相关测量当独立信息，忽略理论误差方向 |
| 干涉、角关联与自旋信息 | 从振幅和相空间推导被积分消掉的信息 | 新的可测关联或机制区分能力 | 忽略接受度、不可重建变量、量子干涉或负权重 |
| 受控极限与系统展开 | 在软/共线/重质量/阈值/大 N 等适用极限建立展开，再验证修正 | 误差可控的新结论或统一描述 | 用渐近结果冒充全域精确结论 |
| 理论误差压低与稳健比值 | 识别误差相关结构，构造比值/组合或补缺失阶次 | 可靠的误差降低与灵敏度提升 | 同时抵消目标信号，或未经验证地假设完全相关 |
| 重新解释公开结果 | 将模型预测映射至公开响应/似然，先复现已知 benchmark | 明确的新约束、盲区或机制判断 | 只扫描参数、未验证 recast、将 simplified-model 限制直接套用 |
| 解析结构、幺正性与一致性界 | 在明确假设下利用解析性、色散关系、正性等约束 | 新界、反例或假设适用边界 | 忽略无质量极点、减除、边界项或高能假设 |
| 非微扰与独立方法交叉验证 | 格点/和规则/色散/实验约束在共同定义下比较 | 可定位的系统误差、稳健预言或方法边界 | 方案、尺度、有限体积或连续极限不匹配 |
| 测量方法与统计信息 | 将可观测量/似然设计直接联系物理可识别性，评估 nuisance | 可校准、可覆盖的物理参数测量能力 | 仅报告 ML 分类准确率，不验证偏差、覆盖率或域偏移 |

实验任务优先结合 experimental-selection 指南。这些策略不是必须采用的新方法；提高关键测量精度、扩展关键区域和独立复核本身可以产生重要贡献，不要求改变推导结构。

选中后写三句话：瓶颈是什么；这个策略具体改变哪个推导/观测步骤；即使工具名称删去，新增物理结论是什么。没有第三句话就返回瓶颈诊断。
